# devdoc — 开放平台文档

## 搜索开放平台文档
```
Usage:
  dws devdoc article search [flags]
Example:
  dws devdoc article search --query "OAuth2 接入" --page 1 --size 10 --format json
Flags:
      --query string     搜索关键词 (必填)
      --page string      页码 (默认 1)
      --size string      每页数量 (默认 10)
```

## 意图判断

- 用户说"开发文档 / API 文档 / 接口文档 / 调用报错" → `devdoc article search`

## 相关性、分页与搜索止损

- 优先原主题短语。指定查询词、页数、每页条数时原样执行，不擅自换词或缩减分页；空页也如实记录。未指定时先小页检索，按相关性和用户完整性要求决定续页，不默认翻全量。
- 按标题、摘要核对产品、动作和接口主题。有返回不等于相关命中；完全无关与空结果都不能充当目标文档。摘要未提供的信息不能当成已读正文或已验证接口行为。
- 普通查找无相关命中时，最多再用一个有依据的同义词或接口名改写；仍未命中就停止并说明尝试与限制。用户明确要求广搜时再扩大范围，不连续轮换近义词、切 AISearch 或读 help 碰运气。
- 按实际链接去重，保留要求的标题、摘要、链接和分类，不猜链接。分别说明相关资料、无关返回和空页；未搜到不代表接口不存在。
- 用户要求整理返回结果时，即使结果全不相关，也将真实条目按要求的标题、摘要、链接去重列出，并标为“无关/不满足主题”；不能只说“查过三页”而遗漏交付列表，也不能把这些条目称为目标文档。纯粹找目标文档则只需报告无相关命中。
- 混合应用管理任务中文档未命中只阻塞依赖文档才能确定的步骤；已有可信参数的独立操作仍可继续。不为文档搜索创建应用、改权限或建版本。
- 已知命令直接执行，参数确有疑问时才查一次精确 leaf。只整理用户所需字段，原始 JSON 留在轨迹，不反复复述。所有命令带 `--format json`。
